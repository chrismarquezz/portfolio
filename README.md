# Chris Marquez | Portfolio

This is my personal portfolio website built with **React**, styled using **Tailwind CSS**, animated with **Framer Motion**, and deployed with **Vercel**. It presents my **skills**, **experience**, and **projects** in a structured, interactive format similar to a professional resume.  

## Features

- **React**: Component-based architecture enabling maintainable and scalable code.  
- **Tailwind CSS**: Utility-first styling for a clean, modern design.  
- **Framer Motion**: Smooth animations and transitions for enhanced user experience.  
- **Vercel Deployment**: Fast and reliable hosting with integrated CI/CD.  
- **Resume-like Layout**: Clear presentation of professional experience, skills, and projects.  

## Technologies Used

- **React** – JavaScript library for building user interfaces  
- **Tailwind CSS** – Utility-first CSS framework  
- **Framer Motion** – Animation library for React  
- **Vercel** – Hosting and deployment platform  
- **Create React App (CRA)** – Tooling and build setup for React projects  

## Goals

- Highlight professional experience and technical skills.  
- Showcase projects with detailed descriptions and links.  
- Provide a visually engaging, organized, and user-friendly layout that reflects personal style.
